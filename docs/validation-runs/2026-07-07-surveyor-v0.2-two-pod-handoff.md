## Multiagent Milestone

The local operating model is now confirmed manually:

- The Surveyor v0.2 agent works in its own checkout/worktree and branch: `headless-surveyor-v0.2-dev`.
- The Trainer v0.2 agent works in a separate checkout/worktree and separate branch.
- The two agents can work in parallel without changing each other's physical branch.
- Coordination is manual; no automatic multiagent orchestration is implemented yet.
- Each agent remains responsible for reviewing, testing, committing, and publishing only its own branch.
